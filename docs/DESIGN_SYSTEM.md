# Design system

Tokens y tipografías están centralizados en `src/styles/global.css`. La identidad usa blanco predominante, superficies azul grisáceo y azul marino para acciones y titulares. Componentes: Header, BrandLogo, ServiceCard, ContactFormDemo. Motion: reveal y stagger suaves; GSAP, ScrollTrigger y scroll snapping se conservan; `prefers-reduced-motion` deja el contenido visible.
